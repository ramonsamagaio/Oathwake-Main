# Artes auxiliares — laboratório Romestead/Alabaster

Esta pasta agora guarda somente as artes auxiliares de clima e iluminação criadas para o laboratório.
Os pisos, árvores e pedras rasterizados do Romestead ficam em `../romestead_native_png`.

## Arquivos

- `cloud_layer.svg`: camada visual repetida pelo sistema de clima.
- `light_cookie.svg`: textura radial das luzes locais.

Os SVGs antigos de piso e objetos foram removidos para evitar confusão com os PNGs nativos usados pela cena.
